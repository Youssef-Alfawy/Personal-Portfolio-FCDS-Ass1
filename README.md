# Personal Portfolio – FCDS College Assignment

## About The Project

This project was developed as a college assignment for the **Web Development Course at the Faculty of Computer and Data Science (FCDS)**.

The original assignment was to create a Personal Profile Card. I expanded the idea into a complete personal portfolio website to showcase my profile, technical skills, learning journey, and projects.

## Features

- Personal profile and introduction
- Student information
- Technical skills and technologies
- Currently learning section
- Featured projects
- Education and career journey
- Social media links
- Contact form interface
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Project Purpose

The main goal of this assignment was to apply HTML and CSS concepts in a practical project while improving my web development and design skills.
